## GLib function evidence and compatibility ceiling

CODE: exact Cargo registry source `glib-0.18.5/src/variant.rs:843–854` constructs `VariantStrIter` from `Variant::array_iter_str`. Iterator fields are private and its constructor is crate-private (`variant_iter.rs:102–116`). `impl_get` passes immutable `&p` as a C out-argument then calls `CStr::from_ptr(p)` (`:118–130`). `next`, `nth`, `last`, `next_back`, `nth_back` call it (`:138–195`). Direct `count`/`size_hint` do not. Advisory: https://rustsec.org/advisories/RUSTSEC-2024-0429.html (unsound informational; affected >=0.15,<0.20; fixed >=0.20).
