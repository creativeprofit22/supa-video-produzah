## Verification is automated only

This is a single-user personal app. Screen-reader and other assistive-technology checks, and any manual human verification (keyboard walkthroughs, listening, eyeballing output), are out of scope. Never request them, list them as open gaps, or use them as a completion gate. All verification must be automated and run by the agent (tests, scripted real-app runs, measurements, agent-inspected screenshots). Existing automated tests, including accessibility tests, stay.
