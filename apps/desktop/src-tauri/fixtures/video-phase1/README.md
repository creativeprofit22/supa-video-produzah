# Phase 1 single-clip fixture

This directory contains the canonical deterministic media fixture and a strict V1 Supa Video Producer project that references it with the project-relative locator `single-clip.mp4`.

## Provenance and rights

The video and audio are entirely self-generated by FFmpeg's `testsrc2` and `sine` filters. No third-party media is present, so the fixture does not carry third-party media rights or attribution requirements.

The checked-in MP4 bytes are canonical. The command pins practical source, timing, codec, threading, and metadata options, but a different FFmpeg or libx264 build may produce a valid file with different bytes. Verify the committed artifact against the SHA-256 below instead of expecting cross-build byte identity.

## Generation environment

- Platform: Microsoft Windows 10 x86_64, build `10.0.19045.6466`
- FFmpeg: `8.1.2-full_build-www.gyan.dev`
- ffprobe: `8.1.2-full_build-www.gyan.dev`

Run from the repository root in a POSIX-compatible shell:

```sh
ffmpeg -hide_banner -loglevel error \
  -f lavfi -i "testsrc2=size=320x180:rate=30:duration=2" \
  -f lavfi -i "sine=frequency=1000:sample_rate=48000:duration=2" \
  -map 0:v:0 -map 1:a:0 \
  -c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p \
  -profile:v high -level:v 3.0 -r 30 -g 30 -keyint_min 30 \
  -sc_threshold 0 -bf 2 -refs 3 -threads:v 1 \
  -c:a aac -b:a 128k -ar 48000 -ac 1 -threads:a 1 \
  -fflags +bitexact -flags:v +bitexact -flags:a +bitexact \
  -map_metadata -1 -metadata creation_time=1970-01-01T00:00:00Z \
  -movflags +faststart -y \
  apps/desktop/src-tauri/fixtures/video-phase1/single-clip.mp4
```
